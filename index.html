01 · Khái niệm

Tập hợp là gì?

Tập hợp là một khái niệm cơ bản của toán học — ta không định nghĩa nó mà chỉ mô tả qua các ví dụ và quy ước ký hiệu.

∈

Phần tử thuộc

Nếu a là phần tử của tập A, ta viết a ∈ A. Ngược lại: a ∉ A.

A

Ký hiệu tập hợp

Tập hợp thường ký hiệu bằng chữ in hoa: A, B, C, X, Y… Phần tử viết chữ thường: a, b, x…

{}

Dấu ngoặc nhọn

Mọi phần tử của tập hợp được đặt trong cặp ngoặc nhọn { }, cách nhau bởi dấu ; hoặc ,.

A = { 0 ; 1 ; 2 ; 3 ; 4 }   ⟹   1 ∈ A   ·   7 ∉ A

Hai cách xác định một tập hợp

CÁCH 1
✎

Liệt kê các phần tử

Viết ra tất cả phần tử của tập hợp trong ngoặc nhọn. Dùng khi tập hợp có ít phần tử hoặc hữu hạn.

A = { 0 ; 1 ; 2 ; 3 ; 4 }
ℕ < 5 5 phần tử

ƒ

Mô tả tập hợp bằng một mệnh đề điều kiện. Dùng được cho cả tập hợp vô hạn phần tử.

A = { n ∈ ℕ | n < 5 }
n ∈ ℕ n < 5
CHÚ Ý

Một tập hợp có thể được xác định bằng biểu đồ Ven — hình vẽ đường cong khép kín bao quanh các phần tử của nó. Hai cách trên là cách viết, biểu đồ Ven là cách vẽ.

03 · Quan hệ

Tập hợp rỗng và tập hợp con

A ⊂ B
A ⊂ B ⟺ ( ∀x, x ∈ A ⟹ x ∈ B )
Tính phản xạ: A ⊂ A với mọi tập hợp A.
Tập rỗng: ∅ ⊂ A với mọi tập hợp A. Tập rỗng không chứa phần tử nào.
Tính bắc cầu: A ⊂ B và B ⊂ C ⟹ A ⊂ C.
∅ = { } ∅ ⊂ A A ⊂ A
04 · Đẳng thức

Hai tập hợp bằng nhau

Hai tập hợp bằng nhau khi chúng có đúng cùng một tập phần tử — không hơn, không kém.

A = B
A = B ⟺ ( A ⊂ B và B ⊂ A )
⟺ ( ∀x, x ∈ A ⟺ x ∈ B )
VÍ DỤ

A = { n ∈ ℕ | n là ước của 6 } = {1; 2; 3; 6}
B = { 1 ; 2 ; 3 ; 6 }  ⟹  A = B

05 · Phép toán thứ nhất

Giao của hai tập hợp — A ∩ B

A ∩ B
A ∩ B = { x | x ∈ A và x ∈ B }
x ∈ A ∩ B ⟺ ( x ∈ A và x ∈ B )
A ∩ A = A — giao với chính nó không đổi.
A ∩ ∅ = ∅ — giao với rỗng luôn rỗng.
A ∩ B ⊂ A và A ∩ B ⊂ B — giao là tập con của cả hai.
Giao hoán: A ∩ B = B ∩ A.

Ví dụ

A = {1;2;3;4} , B = {3;4;5;6}
⟹ A ∩ B = {3;4}

06 · Phép toán thứ hai

Hợp của hai tập hợp — A ∪ B

A ∪ B
A ∪ B = { x | x ∈ A hoặc x ∈ B }
x ∈ A ∪ B ⟺ ( x ∈ A hoặc x ∈ B )
A ∪ A = A và A ∪ ∅ = A.
A ⊂ A ∪ B và B ⊂ A ∪ B — hợp chứa cả hai.
Giao hoán: A ∪ B = B ∪ A.
Kết hợp: (A ∪ B) ∪ C = A ∪ (B ∪ C).

Ví dụ

A = {1;2;3;4} , B = {3;4;5;6}
⟹ A ∪ B = {1;2;3;4;5;6}

07 · Phép toán thứ ba & tư

Hiệu A \ B và phần bù CAB

A \ B
A \ B = { x | x ∈ A và x ∉ B }
Nếu B ⊂ A thì CAB = A \ B
(phần bù của B trong A)
A \ A = ∅ — lấy A trừ chính nó, còn rỗng.
A \ ∅ = A và ∅ \ A = ∅.
KHÔNG giao hoán: A \ B ≠ B \ A (nói chung).

Ví dụ

A = {1;2;3;4} , B = {3;4;5;6}
A \ B = {1;2}  ·  B \ A = {5;6}

08 · Tập số

Các tập hợp số quen thuộc

Quan hệ bao hàm

ℕ = {0; 1; 2; 3; …}

Tập số tự nhiên. ℕ* = ℕ \ {0} là tập số tự nhiên khác 0.

ℤ = {…; −2; −1; 0; 1; 2; …}

Tập số nguyên — gồm số nguyên âm, số 0 và số nguyên dương.

ℚ = { m/n | m, n ∈ ℤ, n ≠ 0 }

Tập số hữu tỉ — mọi số viết được dưới dạng phân số.

ℝ

Tập số thực — gồm số hữu tỉ và số vô tỉ (√2, π, e…).

09 · Tương tác

Khoảng — Đoạn — Nửa khoảng

Kéo hai thanh trượt để thay đổi a và b, rồi chọn kiểu khoảng để xem ký hiệu tương ứng.

[ 2 ; 7 ] = { x ∈ ℝ | 2 ≤ x ≤ 7 }
10 · Vận dụng

Ví dụ tổng hợp — trên trục số thực

ĐỀ BÀI

Cho hai tập hợp

A = [ −3 ; 4 ]
B = ( 1 ; 6 ]

Tìm A ∩ B, A ∪ B, A \ B, B \ A.

LỜI GIẢI

Biểu diễn trên trục số

A ∩ B = ( 1 ; 4 ]
A ∪ B = [ −3 ; 6 ]
A \ B = [ −3 ; 1 ]
B \ A = ( 4 ; 6 ]
∩

Giao — phần chung

Chỉ giữ lại những điểm thuộc cả hai. Nếu hai khoảng rời nhau hoàn toàn, giao bằng ∅.

∪

Hợp — gộp lại

Lấy tất cả điểm của cả hai, bỏ phần trùng. Kết quả thường là một khoảng rộng hơn.

\

Hiệu — loại trừ

Lấy A rồi gạch bỏ những điểm nằm trong B. Chú ý đầu mút: mở hay đóng phụ thuộc vào B.

MẸO

Luôn vẽ hai tập lên cùng một trục số trước khi kết luận. 90% lỗi sai ở dạng bài này đến từ việc xác định sai đầu mút mở/đóng.
