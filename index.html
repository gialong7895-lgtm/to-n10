01 · Khái niệm

Tập hợp & cách xác định

✎

Liệt kê phần tử

Viết hết phần tử trong ngoặc nhọn.

A = {0;1;2;3;4}
ƒ

Tính chất đặc trưng

Mô tả bằng mệnh đề điều kiện.

A = {n ∈ ℕ | n < 5}
Biểu đồ Ven
KHÁI NIỆM

Tập hợp ký hiệu chữ in hoa, phần tử trong { }. a ∈ A — a thuộc A · a ∉ A — a không thuộc A · n(A) là số phần tử. Tập không có phần tử nào gọi là tập rỗng ∅.

VÍ DỤ

D = { n ∈ ℕ | n là số nguyên tố, 5 < n < 20 } ⟹ D = {7; 11; 13; 17; 19}, n(D) = 5.

02 · Quan hệ giữa các tập hợp

Tập con & hai tập hợp bằng nhau

T ⊂ S
T ⊂ S ⟺ ( ∀x, x ∈ T ⟹ x ∈ S )
S = T ⟺ ( S ⊂ T và T ⊂ S )
T ⊂ T ∅ ⊂ T T ⊂ S, S ⊂ R ⟹ T ⊂ R
KHÁI NIỆM

Tập con: T ⊂ S khi mọi phần tử của T đều thuộc S. Bằng nhau: S = T khi S ⊂ T và T ⊂ S.

03 · Các phép toán trên tập hợp

Bốn phép toán cơ bản

∩
Giao
S ∩ T = { x | x ∈ S và x ∈ T }
∪
Hợp
S ∪ T = { x | x ∈ S hoặc x ∈ T }
\
Hiệu
S \ T = { x | x ∈ S và x ∉ T }
C
Phần bù
Khi T ⊂ S: CST = S \ T
Minh hoạ giao trên trục số thực

VÍ DỤ GIAO

C = {4; 7; 27}, D = {2; 4; 9; 27; 36}
⟹ C ∩ D = {4; 27}

VÍ DỤ HỢP & HIỆU

C = {2;3;4;7}, D = {−1;2;3;4;6}
⟹ C ∪ D = {−1;2;3;4;6;7} · C \ D = {7}

04 · Tập số & tập con của ℝ

Các tập hợp số & khoảng – đoạn – nửa khoảng

Bao hàm
Khoảng ( ) và Đoạn [ ] trên trục số
Các tập con thường dùng của ℝ
(a ; b)Khoảng{ x | a < x < b }
[a ; b]Đoạn{ x | a ≤ x ≤ b }
[a ; b)Nửa khoảng{ x | a ≤ x < b }
(a ; b]Nửa khoảng{ x | a < x ≤ b }
(−∞ ; b)Nửa khoảng{ x | x < b }
[a ; +∞)Nửa khoảng{ x | x ≥ a }
GHI NHỚ

( ) — đầu mút không lấy · [ ] — đầu mút có lấy.
