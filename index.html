01 · Khái niệm cơ bản

Tập hợp & phần tử

Tập hợp là khái niệm cơ bản của toán học — ta mô tả qua các phần tử của nó.

∈

Phần tử thuộc

a ∈ S — a là phần tử của tập hợp S.

∉

Không thuộc

a ∉ S — a không là phần tử của S.

n()

Số phần tử

n(S) — ký hiệu số phần tử của tập S.

KHÁI NIỆM

Tập hợp ký hiệu bằng chữ in hoa, phần tử trong ngoặc nhọn { }. Tập không có phần tử nào gọi là tập rỗng ∅.

02 · Phương pháp

Hai cách xác định tập hợp

✎

Liệt kê phần tử

Viết ra tất cả phần tử trong ngoặc nhọn.

A = { 0 ; 1 ; 2 ; 3 ; 4 }
ƒ

Chỉ ra tính chất

Mô tả bằng mệnh đề đặc trưng — dùng cho tập vô hạn.

A = { n ∈ ℕ | n < 5 }
KHÁI NIỆM

Biểu đồ Ven — minh hoạ tập hợp bằng một hình phẳng bao quanh bởi một đường kín.

VÍ DỤ

D = { n ∈ ℕ | n là số nguyên tố, 5 < n < 20 } ⟹ D = {7; 11; 13; 17; 19} · n(D) = 5.

03 · Quan hệ giữa các tập hợp

Tập con & hai tập hợp bằng nhau

T ⊂ S
T ⊂ S ⟺ ( ∀x, x ∈ T ⟹ x ∈ S )
S = T ⟺ ( S ⊂ T và T ⊂ S )
T ⊂ T ∅ ⊂ T T ⊂ S, S ⊂ R ⟹ T ⊂ R
KHÁI NIỆM

Tập con: T ⊂ S khi mọi phần tử của T đều thuộc S. Bằng nhau: S = T khi S ⊂ T và T ⊂ S.

04 · Phép toán trên tập hợp

Giao của hai tập hợp — S ∩ T

S ∩ T
S ∩ T = { x | x ∈ S và x ∈ T }

Ví dụ

C = {4; 7; 27} , D = {2; 4; 9; 27; 36}
⟹ C ∩ D = {4; 27}

[1;+∞) ∩ (−∞;3] = [1;3]
KHÁI NIỆM

Giao của hai tập hợp S và T là tập hợp gồm các phần tử thuộc cả S và T.

05 · Phép toán trên tập hợp

Hợp của hai tập hợp — S ∪ T

S ∪ T
S ∪ T = { x | x ∈ S hoặc x ∈ T }

Ví dụ

C = {2; 3; 4; 7} , D = {−1; 2; 3; 4; 6}
⟹ C ∪ D = {−1; 2; 3; 4; 6; 7}

S ∪ S = S S ∪ ∅ = S
KHÁI NIỆM

Hợp S ∪ T gồm các phần tử thuộc S hoặc thuộc T. Công thức đếm: n(S∪T) = n(S) + n(T) − n(S∩T).

06 · Phép toán trên tập hợp

Hiệu S \ T & phần bù CST

S \ T
S \ T = { x | x ∈ S và x ∉ T }
Nếu T ⊂ S thì CST = S \ T

Ví dụ

D = {−2; 3; 5; 6} , E = {2; 3; 5; 7}
D \ E = {−2; 6}  ·  E \ D = {2; 7}

KHÁI NIỆM

Hiệu S \ T gồm phần tử thuộc S nhưng không thuộc T. Khi T ⊂ S, gọi S \ T là phần bù của T trong S, ký hiệu CST. Chú ý: CSS = ∅.

07 · Tập số & tập con của ℝ

Các tập hợp số & khoảng – đoạn – nửa khoảng

Bao hàm
ℕ = {0;1;2;…} ℤ = {…;−1;0;1;…} ℚ = {m/n | n≠0} ℝ = ℚ ∪ vô tỉ
Các tập con thường dùng của ℝ
(a ; b) Khoảng { x ∈ ℝ | a < x < b }
[a ; b] Đoạn { x ∈ ℝ | a ≤ x ≤ b }
[a ; b) Nửa khoảng { x ∈ ℝ | a ≤ x < b }
(a ; b] Nửa khoảng { x ∈ ℝ | a < x ≤ b }
(−∞ ; b) Nửa khoảng { x ∈ ℝ | x < b }
[a ; +∞) Nửa khoảng { x ∈ ℝ | x ≥ a }
GHI NHỚ

( hoặc ) = đầu mút không lấy · [ hoặc ] = đầu mút có lấy.
